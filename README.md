# Odyssey 3.14: The Voyage

A pedagogical game for learning and applying the Odyssey 3.14 approach to business model innovation
(Lehmann-Ortega, Musikas and Schoettl, HEC Paris). Built by Adam Wielgos for the HEC Master in Marketing course
"Reinventing your business model with Odyssey 3.14", Assignment 3, option 2.

Students sail from Ithaca (their business today) through the Sea of the Value Proposition (directions 1 to 7) and the
Sea of the Value Architecture (directions 8 to 14), survive Aeolus' storm (two dice that force a proposition and an
architecture direction together) and defend their idea before a council of stakeholders on Olympus.

## Develop

```
npm install
npm run dev
```

Stack: React, Three.js (React Three Fiber, drei), Rapier physics, postprocessing. Deployed on Vercel.
